Cette page vous permet de gérer simplement les adresses associées à votre compte professionnel Wédis.

Vous y retrouvez l’ensemble de vos adresses de livraison et de facturation, présentées de façon claire : intitulé, société, rue, code postal, ville, pays et éventuelles précisions utiles pour le livreur.

Depuis cette page, vous pouvez :
- ajouter une nouvelle adresse pour un site, un établissement ou un service différent ;
- modifier une adresse existante si une information change (contact, étage, accès, horaires, etc.) ;
- supprimer une adresse dont vous n’avez plus l’usage.

Pour assurer un traitement rapide et fiable de vos commandes, veillez à :
- vérifier régulièrement que vos adresses sont à jour avant de valider une commande ;
- distinguer clairement vos adresses de livraison de vos adresses de facturation lorsque c’est nécessaire ;
- préciser, si besoin, les informations d’accès importantes (code, interphone, zone de déchargement, horaires de réception).

Vos adresses sont utilisées uniquement pour le traitement de vos commandes et le bon acheminement de vos livraisons. Vous gardez à tout moment la maîtrise des informations enregistrées dans votre espace compte.
