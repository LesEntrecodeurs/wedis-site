# Mot de passe oublié

Vous avez oublié votre mot de passe ? Cette page vous permet de retrouver rapidement l’accès à votre espace client Wédis, de manière simple et sécurisée.

## Réinitialiser votre mot de passe

Pour recevoir un lien de réinitialisation :

1. Saisissez l’adresse e-mail utilisée pour votre compte professionnel Wédis.
2. Validez votre demande de réinitialisation.
3. Consultez votre messagerie et suivez le lien reçu pour choisir un nouveau mot de passe.

Pour votre sécurité, le lien de réinitialisation est limité dans le temps et ne peut être utilisé qu’une seule fois.

## Si vous ne recevez pas l’e-mail

Si vous ne voyez pas l’e-mail de réinitialisation dans les minutes qui suivent :

- vérifiez vos dossiers « courriers indésirables » ou « spam » ;
- assurez-vous que vous avez bien saisi l’adresse utilisée pour créer votre compte Wédis ;
- si besoin, renouvelez la demande après quelques instants.

En cas de difficulté persistante (adresse inconnue, compte bloqué, plusieurs comptes possibles), vous pouvez contacter directement les équipes Wédis : elles vous accompagneront pour sécuriser l’accès à votre espace client et remettre votre compte en service dans les meilleures conditions.
