# Décisions du client

Ce que le client a explicitement tranché, avec ses mots. Le système s'y tient : il ne repose pas une question déjà tranchée ici.

```json
{
	"decisions": [
		{
			"kind": "defer",
			"scope": {
				"kind": "question",
				"questionId": "legal-hebergeur"
			},
			"quote": "pas d'informations pour le moment",
			"consequence": "Les mentions légales pourront rester incomplètes tant que l’hébergeur n’est pas renseigné ; il faudra ajouter cette information avant la mise en ligne définitive du site."
		}
	]
}
```
